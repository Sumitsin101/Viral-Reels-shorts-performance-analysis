# Viral-Reels-shorts-performance-analysis
Data anlytics project analyzing viral reels and shorts and finding useful insights using python, MySQL ,PowerBI

# 📊 Data Analytics Project – End-to-End Analysis & Dashboard

## 📌 Overview

This project demonstrates an end-to-end **data analytics workflow**, starting from raw data ingestion to insights delivery through dashboards and presentations.
The objective is to analyze the dataset, uncover trends and patterns, and communicate insights using **SQL, Python, and Power BI** in a business-friendly manner.

---

## 📂 Dataset

* The dataset contains structured data relevant to the analysis objectives.
* Data was initially loaded using **Python** for exploration and cleaning.
* After cleaning, the data was stored and queried using **MySQL** for analysis.


## 🛠 Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib/Seaborn) – Data loading, EDA, and cleaning
* **MySQL** – SQL queries and analytical transformations
* **Power BI** – Interactive dashboard and data visualization
* **Gamma** – Presentation (PPT) creation
* **Jupyter Notebook** – Analysis and documentation

---

## 🔍 Project Steps

1. **Data Loading**

   * Imported the dataset into Python using Pandas.

2. **Exploratory Data Analysis (EDA)**

   * Checked data structure, distributions, and summary statistics.
   * Identified missing values, outliers, and inconsistencies.

3. **Data Cleaning**

   * Handled missing values and duplicates.
   * Standardized data types and column names.
   * Prepared clean data for SQL analysis.

4. **SQL Analysis (MySQL)**

   * Loaded cleaned data into MySQL.
   * Wrote SQL queries to answer key business questions.
   * Performed aggregations, joins, and filtering.

5. **Dashboard Development**

   * Connected Power BI to the MySQL database.
   * Built interactive dashboards with KPIs and visual insights.

6. **Reporting & Presentation**

   * Created a structured analytical report.
   * Designed a professional PPT using Gamma to present findings.

---

## 📈 Dashboard

The **Power BI dashboard** provides:

* Key performance indicators (KPIs)
* Trends and comparisons
* Interactive filters for deeper insights


## 📊 Results & Insights

* Identified key trends and patterns within the data.
* Highlighted performance metrics and areas of improvement.
* Provided data-driven insights to support decision-making.



## ▶️ How to Run the Project

1. Clone this repository
2. Open the Jupyter Notebook and run the Python scripts for EDA and cleaning.
3. Import the cleaned dataset into **MySQL**.
4. Execute the provided SQL queries.
5. Open the **Power BI** file and refresh the data connection.
6. Review the report and presentation for insights.
